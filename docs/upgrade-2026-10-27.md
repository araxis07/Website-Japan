# Japan travel follow-up — 2026-10-27

The approved follow-up preserves the Japanese paper/night palette, existing URLs, saved trips and three languages. It makes the first-time visitor's path shorter, adds personal stops without a geocoding service, and improves the accuracy and visibility of published travel facts. No account, paid map subscription or guessed production domain was introduced.

## Verification

- ESLint, TypeScript and the production build pass; 182 static routes generated. No dependencies were added. `npm audit --audit-level=high` reports zero known vulnerabilities. Credential-pattern checks and the deployment-checker self-test pass.
- The suite covers 172 cases across desktop Chromium and mobile WebKit. Two intentionally skip: the pre-existing WebKit development-image-observer limitation and a duplicate cross-engine portability run in the mobile project. Both macOS and Linux screenshots were visually inspected before updating their platform-specific references; the Linux review also caught and corrected overlapping decorative Japanese text. GitHub Actions is the authoritative full Linux result for each pushed commit.
- Axe reports zero automated WCAG A/AA violations across five task routes × two themes × two browser projects, including opened personal-stop, export and origin controls. Existing 320px reflow and new 200% root-font checks pass. Root-font enlargement is not proof of OS/browser zoom or screen-reader behavior.
- An actual HTTP LAN origin was tested in Chromium: `isSecureContext`, `crypto.subtle` and `crypto.randomUUID` were all false/unavailable; a personal stop and edited trip survived reload with no page errors. This supplements the deterministic API-unavailable regression.
- A separate live Kyoto map loaded nine real OSM tiles with no failed tiles; the map and Okinawa scene were visually inspected. The normal suite continues to use mocked map tiles. This single check is not an OSM availability guarantee.
- JSON and library downloads were imported through Chromium → WebKit → Chromium without losing the fixture. Offline HTML opened as a local file with the network disabled in both engines. Private-stop validation, failed-write draft retention, redacted exports and deletion confirmation are covered.
- Link reachability checked 134 official URLs: 125 responded successfully, nine were flagged. A second web check could read the Tohoku Bandai Bridge page and both JR East pages. Zuihoden (500), Taito tourism (timeout), Kagoshima tourism (503), Nagoya tourism (timeout/502), Hokkaido University Museum (timeout/502) and Kansai Airport (403) still need a later reachability check. Their existing review dates were not advanced on the strength of an HTTP check. No 404 was reported and no source was silently substituted.

Physical devices, native-language review, real novice sessions, external calendar applications and production services remain the external work identified above. Missing venue fields are counted above; this release does not claim complete operational information for every venue.
